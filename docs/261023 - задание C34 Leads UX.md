## 4. Продуктовые правила (must-fix)

1. **Фильтр статусов** UI: `all | open | hot | handed_to_crm` (+ actual enum). Server `?status=` **или** client filter — зафиксируй в README.  
2. **Пайплайн hint:** короткий текст «open → Mark hot → Hand to CRM → deal status».  
3. **Deal-status:** для `handed_to_crm` — amount/currency/status заметны (не только `code` в hint).  
4. **Ошибки:** 409 (напр. hot не на open) / 422 — короткий текст, не JSON dump.  
5. **RBAC:** staff-only Mark hot / Hand to CRM; member — read + create? (как сейчас по матрице C27 — не расширять права).  
6. **Empty state:** «Добавьте лид → Mark hot…» если список пуст.
