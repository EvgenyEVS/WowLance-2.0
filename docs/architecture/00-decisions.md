# Зафиксированные решения (черновик)

Сюда складываем продуктово-архитектурные договорённости до сборки итогового документа.

| Дата | Решение | Статус |
|------|---------|--------|
| 2026-10-08 | **Версия документов в storage — в пути.** Снимок комнаты пинит URI (+ checksum). | Принято → [ADR-002](../canon/ADR-002-wowlance-2.0-platform-room.md) |
| 2026-10-08 | **Стратегия после старта:** не провоцировать изменения; при публикации новой версии — уведомление **тимлиду**, Accept / Reject. До Accept работает старая версия. | Принято PO → ADR-002 |
| 2026-10-08 | **Одна универсальная комната** (sale + develop); крупные проекты / обязательный Jira — не scope 2.0. | Принято PO → ADR-002 |
| 2026-10-08 | **CRM:** Hot → handoff, менеджер в CRM. **Order/Invoicing:** пакет комнаты, не счёт лиду. **Не входит в WL: Jira, CRM.** Своя БД на сервис. | Принято → ADR-002 |
| 2026-10-08 | **Кабинет фаундера:** основная аналитика WL + CRM — в **Стратегии**; кнопка «Как дела у команды» → подробности в WL. | Принято → ADR-002 |

Разовые файлы комнаты (скрины отчётов и т.п.): immutable-ключи без обязательного `vN` (`…/wowlance/reports/{uuid}.png`).
