## 1. Зачем

C34–C36 (Leads / Chat+Meet / Earnings+Health) влиты в `main` **после** отчёта C37 (тот прогон был на tip до этой волны). Нужен свежий регресс: подтвердить, что золотой путь и новая UX-волна зелёные вместе.

## 2. Стенд

```powershell
git fetch origin
git checkout main
git pull origin main
docker compose up -d db
cd backend
.\.venv\Scripts\alembic upgrade head   # ожидай 014_c27_room_members (+ новее)
.\.venv\Scripts\pytest -q
.\.venv\Scripts\uvicorn app.main:app --port 8000
# frontend: npm run dev
# опц.: .\scripts\founder-demo.ps1
```

Default: `AUTH_DISABLED=true`, `ROOM_RBAC_DISABLED=true`.  
Отдельно — **один** RBAC spot (см. §4.4).

**Важно:** pytest без поднятой Postgres/`docker compose` зависает или падает — в отчёте зафиксируй env (Docker up / fail).

| ID | Проверка |
|----|----------|
| **C34** | Фильтр лидов `all/open/hot/handed_to_crm`; pipeline hint; deal-status (status + amount/currency) на handed; 409/422 короткий текст; empty state; Mark hot / Hand to CRM скрыты у member при RBAC on |
