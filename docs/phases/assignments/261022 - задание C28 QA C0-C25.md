## 2. Стенд

## 4. Обязательный объём

### 4.1. Pytest
В отчёт: `N passed` / failed list. После suite GET room на `wowlance` → 200.

### 4.2. Золотой путь G1–G10
Как в брифе C0–C13 / отчёте C14–C17 (одна `room_id`).

### 4.3. Нарост C14–C25 (smoke)

| ID | Проверка |
|----|----------|
| C14 | meet ensure + idempotent |
| C15 | assignee из roster; 404 чужой sub |
| C16 | Earned после accept |
| C17 | Terminate ≠ Unassign; outbox MemberTerminated |
| C18 | entitlement → 1× StaffingUnlocked; replay без дубля |
| C19 | deal-status won на handed; UI deal; 409 на open |
| C20 | post/list messages |
| C21 | default internal open; (опц.) strict 401 без token |
| C22 | rematerialize; orphaned_filled если shrink |
| C23 | Suggest/match shortlist; assign из roster |
| C24 | accept → outbox TaskAccepted |
| C25 | health.earnings total/count |

### 4.4. Outbox на одной комнате
Ожидай сосуществование типов: RoomCreated, StaffingUnlocked, HotLeadToCrm, RoomHealthSnapshot, MemberTerminated, TaskAccepted (и др. по сценарию).
