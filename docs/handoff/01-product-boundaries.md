## Роль WowLance

Универсальная **комната исполнения** (sale + лёгкий develop):

| Делает | Не делает |
|--------|-----------|
| Комната, снимок стратегии | Редактор стратегии → **Стратегия (US Closer)** |
| Слоты, roster, matching lite | Верификация фрилансеров → **Talent** |
| Задачи, QG, proof | Полноценная CRM / сделки → **CRM** |
| Прогрев лидов до Hot + история handoff | Регистрация / пароли → **Keycloak** |
| Health / earnings сводки | Счета клиенту-лиду |
| Chat / Meet stubs | Обязательный Jira |

## Соседи платформы

| Сервис | Роль |
|--------|------|
| **Стратегия (US Closer)** | Стратегия продаж, SOP, витрина результатов фаундера |
| **Talent** | Маркетплейс verified фрилансеров |
| **CRM** | Сделки после Hot |
| **Регистрация + Keycloak** | Единый вход, `sub` |
| **Order / Payment / Invoicing** | Пакет комнаты, оплата, счета платформы |

---

## Правила данных

1. У каждого сервиса **своя PostgreSQL**.  
2. Чужие таблицы **не читаем**.  
3. Обмен: **контракты** (HTTPS API / события / снимки).  
4. Стратегия в комнате — **immutable snapshot**; новая версия — Accept тимлида.  
5. Roster в комнате — **снимок** из Talent, matching по локальной БД.  
6. Staffing только после **entitlement** (оплата пакета).  
7. Файлы — object storage; в событиях URI + версия + checksum.
