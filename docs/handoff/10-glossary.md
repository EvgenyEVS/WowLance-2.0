# Глоссарий

| Термин | Смысл |
|--------|--------|
| **Комната (room)** | Рабочее пространство исполнения стратегии в WowLance |
| **Стратегия (US Closer)** | Сервис стратегии продаж и витрины фаундера |
| **Handoff / FounderHandoff** | Передача снимка стратегии в комнату |
| **Snapshot** | Зафиксированная копия стратегии в БД WL |
| **Entitlement** | Право staff’ить после оплаты пакета |
| **Staffing / slots** | Места в команде комнаты |
| **Roster** | Локальный список фрилансеров (снимок из Talent) |
| **Matching lite** | Shortlist из локального roster |
| **Quality Gate (QG)** | Сдача proof → accept/reject тимлида |
| **Hot** | Лид готов к менеджеру → уходит в CRM |
| **Outbox** | Таблица исходящих событий сервиса |
| **Shadow user** | Локальная запись User с тем же Keycloak `sub` |
| **OpenSpec / контракт** | Согласованная схема обмена |
| **aligned / agreed** | Совпадает с кодом / подписан соседом |
| **Stub** | Заглушка соседа до live |
| **Gateway** | Единый вход HTTPS платформы |
| **ADR-002** | Канон границ комнаты 2.0 |

Синонимы событий (arch → факт): см. [REGISTRY](../../contracts/REGISTRY.md).
