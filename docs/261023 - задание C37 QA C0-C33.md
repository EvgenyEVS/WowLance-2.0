## 4. Обязательный объём

### 4.1. Pytest
В отчёт: `N passed` / failed list. Ожидание порядка **~200+** (после C33 было 201).

### 4.2. Золотой путь G1–G10
Одна `room_id`; можно через UI и/или `scripts/founder-demo.ps1` + чеклист `docs/demo/founder-demo.md`.

### 4.3. Нарост C26–C33 (smoke)

| ID | Проверка |
|----|----------|
| C26 | founder-demo.ps1 до UI URL; чеклист открывается |
| C27 | default env: demo жив; при RBAC on: member 403 assign; staff OK |
| C28 | (история) — не повторять весь C0–C25 вручную, если G1–G10 + §4.3–4.5 зелёные; выборочно спорные |
| C29 | Suggest Pick; chat last-N; Accept→Earned refresh; empty/mobile |
| C30 | filter tasks + rejected; reject reason на list |
| C31 | rematerialize/orphaned; unassign/reassign; match empty hint |
| C32 | повтор handoff/entitlement без сюрпризов; 4xx shape; stub logs |
| C33 | `docs/contracts-owners.md` + REGISTRY owners секция на месте |

### 4.4. RBAC spot-check (один прогон)
`ROOM_RBAC_DISABLED=false` (или как в README C27): member не видит Terminate/Assign; chat post OK; вернуть default для остального.

### 4.5. Outbox на одной комнате
Типы сосуществуют: RoomCreated, StaffingUnlocked, HotLeadToCrm, RoomHealthSnapshot, TaskAccepted, MemberTerminated (по сценарию).
