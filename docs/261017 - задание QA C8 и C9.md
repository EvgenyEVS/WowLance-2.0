## 2. Чеклист C8 — Auth

### Режим `AUTH_DISABLED=true` (default `.env`)

| # | Проверка | Ожидание |
|---|----------|----------|
| A0 | GET `/api/v1/rooms/{id}` без Bearer | 200 (как раньше) |
| A1 | UI без login открывает комнату | ок |

### Режим строгий (временно в `.env`)

```text
AUTH_DISABLED=false
AUTH_STUB_JWKS=true
```

Перезапустить uvicorn. По README C8 получить stub-token (обычно `POST /auth/stub-token` или аналог).

| # | Проверка | Ожидание |
|---|----------|----------|
| A2 | GET room **без** Bearer | **401** |
| A3 | GET room **с** `Authorization: Bearer <token>` | **200** |
| A4 | POST `/internal/v1/handoffs` без Bearer | всё ещё 200/201 |
| A5 | UI: Login / paste token → Open room | ок; без токена — уход на login / 401 |
| A6 | Вернуть `AUTH_DISABLED=true` | снова открытый API |

## 3. Чеклист C9 — Hot leads

Комната через handoff (Swagger `POST /internal/v1/handoffs` + `FounderHandoff.sale.json`).

| # | Проверка | Ожидание |
|---|----------|----------|
| L1 | create lead | 201, status `open` |
| L2 | list | лид в списке |
| L3 | mark-hot | `hot` |
| L4 | handoff-crm | `handed_to_crm`, `crm_ref` вида `crm-stub:…` |
| L5 | повтор handoff | `already_handed`, без дубля смысла |
| L6 | handoff из `open` | **409** |
| L7 | без `X-Actor-Sub` на мутации (при AUTH_DISABLED) | **422** |
| L8 | UI LeadsPanel: create → Mark hot → Hand off | статусы меняются |
| L9 | На одной комнате: Leads **и** Tasks/Slots видны | стык с C6/C7 |
