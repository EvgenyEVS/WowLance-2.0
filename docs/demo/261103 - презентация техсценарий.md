## A. За 15–20 минут до встречи

### A1. Поднять стек (рекомендуется Docker)

Из корня `WowLance-2.0`:

```powershell
git checkout main
git pull origin main
docker compose up --build -d
```

| Что | URL |
|-----|-----|
| UI | http://127.0.0.1:8088 |
| API health | http://127.0.0.1:8000/health |
| Swagger (опц.) | http://127.0.0.1:8000/docs |

Ожидание health: `{"status":"ok","service":"wowlance-2"}`.

**Гибрид** (если Docker только для БД): `docker compose up -d db` → uvicorn `:8000` → `npm run dev` (часто `:5173`). Тогда в demo-скрипте и ниже подставьте свой UI-порт.

### A2. Засеять комнату

```powershell
powershell -File scripts/founder-demo.ps1
```

Скопируйте из вывода:

- `room_id = …`
- строку **UI:** `http://127.0.0.1:8088/rooms/<room_id>`  
  (если UI на Vite — порт из скрипта, по умолчанию `5173`; при Docker UI обычно **8088** — откройте тот же path на 8088)

Проверка вручную:

```powershell
curl.exe -s http://127.0.0.1:8000/health
curl.exe -s http://127.0.0.1:8000/api/v1/rooms/<room_id>
```

### A3. Вкладки браузера (заранее)

1. **Комната 2.0** — URL из A2 (полный экран).  
2. Опционально: **Swagger** `/docs` — только если спросят про API.  
3. Опционально: **1.0 комната** — если нужен «красивый» reference UX рядом.  
4. Опционально: `docs/diagrams/` или ADR — одна схема границ (не обязательно).

Не держите открытыми логи uvicorn на шаринге экрана.

### A4. Запасной план

| Симптом | Действие |
|---------|----------|
| Docker не стартует | Включить Docker Desktop; повторить `docker compose up -d` |
| Порт 8000/8088 занят | Остановить чужой процесс или сменить порт в compose / `-ApiBase` |
| Скрипт 401 на `/internal` | Demo с `INTERNAL_AUTH_DISABLED=true` (default); иначе задать `INTERNAL_SERVICE_TOKEN` |
| UI пустой / CORS | API и UI из одной инструкции (compose); не смешивать старый `:5173` с другим API без proxy |

## B. Во время презентации (клики по минутам)

Спикер говорит по [тезисам](261103%20-%20презентация%20тезисы.md); оператор экрана делает шаги ниже.

### B0. Старт (30 сек)

1. Открыть **UI комнаты** (вкладка 1).  
2. Показать адресную строку: `/rooms/<uuid>` — «одна комната = один id».

### B1. Шапка комнаты (1 мин)

Показать без кликов:

- название (sale demo / Cold Calling);  
- badge **Staffing unlocked**;  
- founder / type / timezone.

**Фраза:** стратегия уже в снимке; staffing открыт после entitlement.

### B2. Strategy snapshot (1 мин)

Проскроллить блок **Strategy**:

- Offer, Audience, Hot criteria, documents (URI текстом).

**Не** обязательно Accept/Reject pending, если pending нет после demo-скрипта.

### B3. Meet (30 сек)

- Показать ссылку Meet (Jitsi stub).  
- Клик **Re-ensure** (или Ensure) → ссылка та же / без ошибки — идемпотентность.  
- **Не** обязательно открывать Jitsi в новой вкладке на демо (шум); достаточно показать URL.

### B4. Slots + Roster (2 мин)

1. **Slots:** один seat **filled** (`freelancer-demo-sub`), остальные open.  
2. На open seat: **Suggest** → shortlist → **Pick** / выбор → **Assign** (если хотите живое действие).  
3. Альтернатива короче: только показать filled + «сюда же matching lite и rematerialize».

**Не** жать Terminate без нужды (ломает картинку команды).

### B5. Tasks + Earned (2–3 мин)

1. **Tasks:** задача `Demo first dials` в **done**, proof-ссылка.  
2. Фильтр статусов (если есть): щёлкнуть `done` / `all`.  
3. **Earned:** total **10.00 USD** (stub).  
4. Опционально live: **Add** задачу → Start → Submit proof → **Accept** → Earned станет 20 — только если есть 2 минуты.

### B6. Leads (1–2 мин)

1. Лид в **handed_to_crm**, `crm-stub:…`.  
2. Фильтр `handed_to_crm` / `all`.  
3. Опционально: **Add** новый лид → **Mark hot** → **Hand to CRM**.

### B7. Chat (30–45 сек)

1. Ввести короткое сообщение → **Send**.  
2. Сообщение появляется сразу; подождать ~7 с — soft poll без полного «Loading…».

### B8. Room health (1 мин)

1. **Refresh** — слоты / tasks / leads / earned согласованы с тем, что показали.  
2. **Publish snapshot** — показать `outbox_id` и подпись stub (не live Strategy).

### B9. Финал экрана (30 сек)

Вернуться вверх страницы. Повторить: один URL = весь цикл.

## C. Если спросят «а роли?»

Только если есть время и второй процесс API:

```powershell
# отдельный терминал, RBAC on
$env:ROOM_RBAC_DISABLED="false"
# uvicorn на :8001 из backend/.venv …
```

Иначе **не уходить** в RBAC на основном демо: сказать «роли founder/teamlead/member есть; в demo mode ослаблены».

---

## D. Если спросят «красивый UI»

1. Не спорить со stub-shell.  
2. Переключить на вкладку **1.0** (если подготовлена) — «целевой язык интерфейса».  
3. «В 2.0 запланирована волна visual parity C39–C41 без смены логики».
